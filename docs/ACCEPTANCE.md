# 最终验收标准

## 运行结果

- Go 公开页面：`http://127.0.0.1:18082/`
- Go 后台：`http://127.0.0.1:18082/admin/`
- 健康检查：`http://127.0.0.1:18082/healthz`
- 工程外的转发配置不属于本工程，验收时单独检查其是否只指向 Go Web 服务。

## 功能验收

- 公开首页、应用列表、分类页和详情页可以打开。
- 详情页展示本地图片、应用资料、关键词和“相关链接”页签。
- 相关链接以按钮形式展示，点击后跳转到保存的外部 URL。
- 页面内部链接使用相对路径，部署到非默认端口时不会固定跳转到 `80` 或旧端口。
- 已移除 `/link` 入口及其不需要的链接池页签，访问返回 404。
- 普通浏览器和 Googlebot User-Agent 经过相同的页面处理链。
- 后台界面为中文，登录、退出、站点设置、应用、图片、语言和链接管理可用。
- Worker 能读取印尼语词句文件并以任务方式刷新运行时数据。
- 图片从本地资源提供；工程不保存或提供 APK 文件。
- Go 版本不修改参考工程。

## 安全与脱敏验收

- 工程源码、模板、测试、文档和配置示例不包含旧站域名、旧品牌、旧行业敏感词、个人路径、邮箱、作者注释或外部转发认证信息。
- 管理员密码不出现在回复、源码、文档、日志或验收产物中。
- 转发配置、服务端地址、认证信息和外部端口不在 Go 工程目录内。
- Docker 使用非 root 和只读根文件系统。
- 后台 API 具备登录、会话、CSRF/Origin 和输入校验。

## 自动检查

```sh
go test -count=1 ./...
go test -race -count=1 ./...
go vet ./...
go build ./cmd/site ./cmd/worker
go mod verify
go mod tidy -diff
```

脱敏扫描使用维护者本地保存的敏感项清单执行，不把旧域名、旧品牌、个人绝对路径、邮箱或转发凭据写入仓库文档。扫描范围应覆盖源码、模板、测试、文档和配置示例，并排除二进制图片、运行时存储和临时目录。

扫描命中只能保留许可证标准词、通用测试域名和业务必需的协议字段；旧站域名、旧品牌、个人绝对路径和转发信息必须为零命中。
